# Music

Drop MP3s here with these exact names and the game uses them instead of its generated score.
Any that are missing keep the generated music. Loops should be 1:30–3:00 long and loop cleanly
(no fade-out, no big ending).

| File | When it plays | Loops |
| --- | --- | --- |
| `menu.mp3` | Title, character select and results backdrop | yes |
| `stealth.mp3` | Sneaking, nobody suspects you | yes |
| `tense.mp3` | A guard is suspicious or searching | yes |
| `alert.mp3` | You've been spotted | yes |
| `victory.mp3` | Mission complete | no, 20–40 s |
| `defeat.mp3` | Mission failed | no, 15–30 s |
